# Oracle Cloud Infrastructure (OCI) Access Policy

**Category:** IT Support  
**Effective:** 2026-04-09

## Overview

Oracle Cloud Infrastructure (OCI) is an approved cloud platform at UniGPS. Employees can manage
OCI compute resources, check cloud spend, and raise OCI support tickets directly through
FrontDesk AI — no separate access request or Jira ticket is required.

## What Employees Can Do via FrontDesk AI

All authenticated employees may:
- List and view OCI compute instances in their compartment
- Restart, stop, or start instances (SOFTRESET, STOP, START)
- Check OCI cloud usage and cost data
- Raise and track OCI support incidents

Admin users (engineering leads, CTO) may additionally:
- Launch new compute instances
- Terminate compute instances

## No Approval Required

OCI access through FrontDesk AI is pre-approved. Employees do **not** need to:
- Submit a Jira ticket
- Get manager approval
- File a formal access request

This policy supersedes the general AWS Access guidelines for OCI-specific operations performed
through the FrontDesk AI interface.
